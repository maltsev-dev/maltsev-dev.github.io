# maltsev-dev.github.io

Anatolii Maltsev's site: a static Astro build served from GitHub Pages.

The writing is the bulk of it — sixty-nine posts — and it is meant to be read
without JavaScript. Everything else on the site (theme switching, the command
palette, the filters on the writing index, the sideways tracks on
`/projects/` and `/experience/`) is an enhancement laid over content that is
already on the page.

## Build

```
npm ci
npm run build          # -> dist/
npm run preview        # serves dist/ locally
```

Node 20, Astro 5, static output. No server, no database, no runtime
dependencies in the browser beyond the site's own scripts.

## What gates a deploy

`.github/workflows/` builds on every push to `main`, and the deploy is blocked
by one gate:

```
python _audit_links_astro.py
```

It walks every emitted HTML file in `dist/`, resolves each local `href`/`src`
(and the site's own `og:image` meta tags) against the built output, and fails
the build on anything that does not exist. It also checks the 138 legacy URLs
the previous generator published against `_legacy-urls.json` — those are stubs
that must keep existing, because links from elsewhere still point at them.

To check a build that is not in `dist/`, pass the directory:

```
python _audit_links_astro.py dist-check
```

## Layout

```
src/
  content/posts/      the writing, one Markdown file per post
  content/projects/   the three case studies (frontmatter + legacy HTML)
  data/               milestones, skills, topics, stages, dates
  lib/                llms.txt, schema.org helpers, summarising, tags
  pages/              one file per route
  components/         header, footer, status bar, the architecture figure
  scripts/            os.js (chrome), track.js (the sideways rows),
                      blog-filters.js (the writing index filters), skills.js
  styles/             global.css, os.css, track.css, skills.css
static/               images, og cards, fonts, robots.txt
```

Two directories carry the same names and only one of them is live:

- `src/content/` — the Astro content collections. **This is where posts go.**
- `content/` — the retired generator's corpus. Nothing builds it any more; it
  is kept because `_gen_redirects.py` reads it to derive the legacy URLs the
  redirect stubs are made from. It is not built and not served.

The URL set the retired generator published is recorded twice: the 138 stubs
that still ship are listed in `_legacy-urls.json`, and the complete list of
392 URLs it once served — including the tag pages that no longer have stubs —
is in `docs/legacy-urls.txt`.

## Adding a post

Drop a Markdown file in `src/content/posts/`. The front matter needs a
`title`, and `date` and `tags` are worth setting:

```
---
title: "What the post is about"
date: "2026-11-11"
tags: ["reliability", "security"]
---
```

Everything else is derived: the summary line on the card, the reading time,
the topic it belongs to, the social card in `static/og/`, and the entry in
`llms.txt`, the sitemap and the RSS feed.

The one thing that is not derived is the **topic**. `src/data/topics.ts`
files every post under one of five subjects by hand, and `unassigned()`
reports the posts no topic claims — so a new post has to be given a home
there as well, or the index and the agent map will disagree.

## The generated files

Three of them are generated and should not be edited by hand:

- `/llms.txt` and `/llm.txt` — the agent map, from `src/lib/llm.ts`.
- `/sitemap.xml` — from `src/pages/sitemap.xml.js`.
- `/rss.xml` — from `@astrojs/rss`.

`static/og/*.png` are the social cards, generated by `_gen_og.mjs`.

## CDN

The site is served from GitHub Pages, and the only third-party requests it
makes are the Google Fonts that carry Anton, Inter, JetBrains Mono and
Cascadia Mono Art. The font CSS is loaded from `fonts.googleapis.com` with
`display=swap`, and the site is built to stay legible without it — the
fallbacks are named in `src/styles/global.css` for exactly that reason. Any
new CDN dependency should be added the same way: named fallback, no layout
shift, and nothing the page cannot be read without.
